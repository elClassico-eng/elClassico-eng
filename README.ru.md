### Главный проект: Takt

**Срок спринта с вероятностью, а не на глаз.**

<a href="https://takt34.tech"><img src="https://raw.githubusercontent.com/elClassico-eng/scrumban_app/main/.github/assets/screenshots/simulator-what-if.gif" width="100%" alt="What-if симулятор: изменение оценок пересчитывает прогноз Monte Carlo и критический путь"></a>

- Kanban-доска с WIP-лимитами, которые реально блокируют, классами обслуживания и старением задач по SLE
- Прогноз спринта: критический путь (CPM + PERT) и Monte Carlo по графу зависимостей, P50 / P85
- Каждый прогноз сохраняется и потом сверяется с фактом
